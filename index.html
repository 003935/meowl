Where do I find my auth_token?
  1. Open x.com logged in, in Chrome/Safari/Firefox.
  2. Open DevTools (⌥⌘I) → Application (Chrome) or Storage (Safari/Firefox) → Cookies → https://x.com.
  3. Copy the Value of the auth_token row and paste it above.
The token stays on your computer: it's kept in memory by the local server only while deleting, never saved to disk.
